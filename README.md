## 🚀 About The Project

**Anand Portfolio** is a modern and responsive personal portfolio website designed to showcase my **technical skills, projects, education, achievements, and developer journey**.

The website serves as my professional online presence, allowing recruiters, developers, and visitors to quickly explore my background, technical expertise, and projects.

🔗 **Live Website:**
https://anna748842.github.io/Anand-Portfolio/

---

## ✨ Features

* 🎨 Modern and responsive UI/UX
* 📱 Fully responsive across desktop, tablet, and mobile
* 👨‍💻 Developer profile and introduction
* 🛠️ Technical skills showcase
* 🚀 Project portfolio with project details
* 🎓 Education section
* 📄 Resume access
* 📬 Contact section
* 🌙 Dark/Light theme
* ⚡ Smooth navigation and interactive UI
* 🔗 Social and professional profile links
* 📱 Mobile-friendly layout
