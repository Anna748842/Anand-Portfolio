# ⚙️ Installation

## 1. Clone the repository

```bash
git clone https://github.com/Anna748842/Anand-Portfolio.git
```

## 2. Navigate to the project

```bash
cd Anand-Portfolio
```

## 3. Install dependencies

If the frontend is inside `client`:

```bash
npm --prefix client install
```

For the root project:

```bash
npm install
```

## 4. Configure environment variables

If your backend requires environment variables, create a `.env` file.

Example:

```env
PORT=5000
MONGODB_URI=your_mongodb_connection_string
```

**Do not commit your actual `.env` file or credentials to GitHub.**

## 5. Start the project

If your root `package.json` contains the development script:

```bash
npm run dev
```

Otherwise, start the frontend separately:

```bash
cd client
npm run dev
```

The frontend will normally be available at:

```text
http://localhost:5173
```

# 🏗️ Build for Production

Create a production build using:

```bash
npm run build
```

For a separate frontend:

```bash
cd client
npm run build
```

The generated production files can then be deployed using your configured hosting/deployment workflow.
